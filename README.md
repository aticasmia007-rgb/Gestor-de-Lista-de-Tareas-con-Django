GESTOR DE LISTA DE TAREAS - DJANGO

Proyecto práctico para aprender las bases del framework Django, así como entender con mayor 
profundidad la arquitectura cliente-servidor, el protocolo HTTP, los métodos REST y el modelado
de bases de datos relacionales.

A tener en cuenta, al tener en la BD los identificadores de manera automática según se crean las
listas/tareas, es posible que ids como el 1, 2, 3, etc, ya no existan. Por ello, es conveniente 
ir probando distintos números.
